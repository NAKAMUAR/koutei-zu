# 枝番（部屋・建物）対応

2026-11-10 版。

## 何のための機能か

1つの案件の中に、部屋（2F・3F）や建物（A棟・B棟）があるときに使う。
枝番ごとに視点を①から数える。

- 例：社外案件名「オフィス」、枝番「2F」→ 2F内観目線視点①・2F内観目線視点②
- 例：同じ案件で枝番「3F」→ 3F内観目線視点①（2F とは別の視点）

## 仕組み

枝番は**別の案件にはしない**。視点の「部屋名」として付ける（2026-11-04 からある部屋名の仕組みをそのまま使う）。

- エンジニア入力シート・工程図の視点は `INE1_2F` になる。
- 社外視点名は `2F内観目線視点①` になる。
- 取込キーは `OFFICE55::INE1_2F::1` になる。案件（`OFFICE55`）は同じで、枝番ごとに別の視点として回数を数える。
- 工程図では1つの案件「オフィス」の中に 2F・3F の視点が並ぶ。
- 納品名は `オフィス_2F内観目線視点①_YYMMDD` になる。
- 枝番には日本語も使える（A棟・ロビー など）。「2F,3F」と書くと、枝番ごとの行に分かれる。

## 入力のしかた

### 『案件入力』

案件番号のすぐ下に「枝番」の欄がある。

- 枝番を書くと、② のすべての視点の部屋名に入る。あとから①で足した視点にも入る。
- 枝番を書き換えると、部屋名が空の行と、前の枝番のままの行が新しい枝番になる。前の枝番は隠し列 V に覚えている。
  - 人が別の部屋名を書いた行は、そのまま残す。
- 「前回の視点を呼び出す」は、枝番を書いてあればその枝番の視点だけを呼び出す。
- 『登録一覧』の「枝番」列に記録する。これは見るためだけで、キーには使わない。

### 枝番と視点を1つの画面で選ぶ（2026-11-10 追加・同日に1画面へ変更し、枝番の追加も同じ画面に）

枝番の右の「枝番と視点を画面で選ぶ →」（M列）にチェックすると、「枝番と視点を選ぶ」の画面が開く（`formOpenBranchDialog_`。枝番がまだ空でも開ける）。枝番に「2F,3F」のように2つ以上書いたときも自動で開く。

- 画面の上の「枝番を足す」に 2F・A棟 などを書いて「追加」（または Enter）で枝番が増える。「2F,3F」「2F、3F」でまとめて足せる。足した枝番は、前の枝番と同じ視点が選ばれた状態から始まる（いらなければ外す・「空にする」）。
- 欄ごとに「枝番を消す」ボタンがあり、消した枝番の行は「決定」で②からも消える。
- 「決定」で、画面の枝番の並びがシートの「枝番」にも入る（`saveBranchViews(選択, 枝番の並び)`）。

- 画面には枝番ごとの欄があり、①と同じ区分（外観目線・内観目線…）の番号ボタンが並ぶ。全部の枝番の視点を1つの画面で選べる。
- 欄ごとに「前の枝番と同じにする」「空にする」のボタンがある。
- 「決定」で、選んだ視点が②に入る（`saveBranchViews`・`formRowsFromBranchSel_`）。
  - 残した視点の行は、パターン・社外視点名・登録No をそのまま残す。
- もう一度開くときも M列 にチェックする。いまの選択が入った状態で開く。
- 枝番が2つ以上のとき、シートの①の動き（`formListMergeAll_`・`formGridCodes_`）
  - チェックは、どれかの枝番にある視点に付く。
  - ①で新しくチェックした視点は、全部の枝番に入る。外した視点は、全部の枝番から消える。
  - 画面で付けた枝番ごとの違いは残る。
- 枝番の一覧を書き換えたときの動き（`formApplyBranchList_`）
  - 1つ → 1つ（2F → 3F）は付け替えになる。
  - 一覧から消した枝番は、その行が②から消える。
  - ②は枝番の順に並ぶ。
- 『登録一覧』の「枝番」列には、行ごとにその行の枝番が入る。
- 「登録Noで呼び出す」と、呼び出した視点の枝番が一覧に入る。

### 『案件登録』

「枝番」列を足した場合だけ使える（今の本番のタブには無い）。部屋名の無い視点にだけ `視点_枝番` として付ける（`withBranchRoom_`）。

### エンジニア入力シート

枝番の列は足さない。視点に入るので（`INE1_2F`）、それで分かる。

## 以前の版との違い

2026-11-09 に別の AI が入れた版は、枝番を「別の案件」として扱っていた。

- 社内案件名は `REN.55/1` になっていた。
- 工程図の案件名は「金宝堂〔REN.55 枝番1〕」になっていた。
- 枝番に使えるのは英数字だけだった。

使う人の意図（同じ案件の中の部屋・建物ごとに視点を分ける）と違ったため、2026-11-10 に今の形へ作り直した。

- 前の版を使った登録はまだ無かった。
- 前の版が足した列は、2026-11-10 に片付けた。片付けたのは、エンジニア入力シート3タブの「枝番」列と、『登録一覧』の隠し列「登録時の枝番」。
