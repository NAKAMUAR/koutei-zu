## 3. 手順

### 3-1. 連携スクリプト（管理者用シート）を新しくする

1. `git pull origin main` → `npm test`（すべて passed を確認）。
2. `npm run gas:push`（`.clasp.json` が無ければ docs/08 の 2-9。スクリプトID は `1sCeHkCUuQv9ORNWsO5hJz8jBM7GwfxgAkTasbApf3MvhI6UGGe3PxGQi`）。
   - clasp が使えないときは、Apps Script エディタの「コード.gs」を `sync/Code.gs` の全文で置き換えて保存。
   - `.claspignore` で帳票のスクリプト（`sync/billing/`）は送らない設定になっている。
3. 管理者用シートを再読み込み → メニュー「工程図連携」→「0. かんたん初期設定」→ すべて ✓ を確認（新しい権限は無いので、ふつうは承認画面は出ない）。
4. 確認：
   - 『案件入力』の「前回の視点を呼び出す」の下に「登録Noで直す」の行があること（無ければフォームのどこかを1回触ると出る）。
   - 『会社マスタ』B列の4社（株式会社SUMUS・株式会社 グレイ美術・株式会社ALEG・株式会社エサキホーム）が、初期設定の結果どおり工程図の表記に書き換わったこと。

### 3-2. 帳票スクリプトを雛形ファイルに入れる（初めて）

1. 雛形ファイル →「拡張機能 → Apps Script」（雛形ファイル専用の新しいプロジェクトができる。連携スクリプトとは別）。
2. 「コード.gs」の中身を消して `sync/billing/Billing.gs` の全文を貼り、保存。
3. 歯車 →「"appsscript.json" マニフェスト ファイルをエディタで表示する」をオン → `appsscript.json` を `sync/billing/appsscript.json` の中身で置き換えて保存（工程図・Drive・別のスプレッドシートを使う権限）。
4. 雛形ファイルを再読み込み → メニュー「帳票」→ どれかを押す → 承認（「詳細」→「安全ではないページに移動」→ 権限は「すべて選択」→「許可」）。
5. 確認：請求書タブで「1. 工程図から読み込む」→ 金額の入った案件を選ぶ → 宛先・件名・明細が入る →「2. PDFで発行」→ PDF のリンクが出て、Drive の「工程図_帳票PDF」に保存、『発行一覧』に1行、アプリの「帳票」一覧に「PDF」ボタン付きで出る。
   - **注意**：請求書で発行すると、読み込んだ作業が工程図で「請求済み」になる。試すときはオーナーに断るか、見積書タブで試す。試しに作った帳票は、アプリの帳票一覧から消せる。

### 3-3. 売上総合報告書の雛形を取り込み、10月分を作ってみる

1. 雛形ファイルのメニュー「帳票」→「売上総合報告書：雛形を取り込む（最初に1回）」→ 1章の「売上総合報告書」の URL を貼る。
   → 『売上総合報告書（雛形）』タブができ、結果に区分が9つ（1.オフショア国内〜8.CG工房）出ることを確認。案件の記入（D〜L・O〜W・AA〜AB）が空で、計算式・プルダウンが残っていること。
2. 「売上総合報告書：月を選んで作る」→ `2026-10` → 『売上総合報告書(2026.10月分)』タブができ、アプリの売上登録表（10月）の行が区分ごとに入る。結果の画面に「入らなかった行」「入れる区分が無い行」が出たら、オーナーに伝える。
3. そのタブで「2. PDFで発行」→ 横向きの PDF。
4. 元の報告書（オーナーが手で作った10月分）と見比べて、区分・金額・日付がずれていないかをオーナーと確かめる。月の入り方（25日締め）はアプリの売上登録表の月のまま。

### 3-4. 過去分の取り込み（アプリ。オーナーの操作）

アプリ →「集計・帳票」→「過去分の取り込み」：
1. 旧シート『案件シート(一覧)』で名前ボックスに `A1:AC9299` → コピー → 上の欄に貼る。
2. 管理者用シート『LINEの担当者（10月）』タブを見出しの行から全部コピー → 下の欄に貼る（担当者が付く。社内マニュアルの4件は「対象外」、内容不明の9件は「不明」の完了済みになる）。
3. 「読み取る」→ 一覧を確かめる（LINE で制作中の8件は最初からチェックが外れている）→「登録」。
4. 過去分は保管庫に入り、画面の下「保管している過去分」で検索・シート用コピー・CSV 保存ができる（案件・完了タブには出ない）。以前に作業として取り込んでいた過去分があれば「保管庫へ移す」ボタンが出る。

## 4. 決まったこと（2026-11-03〜04、オーナー）

- 会社名は工程図を正とする。近い表記は自動で合わせる。
- Discord の催促は連絡文の期限に合わせる。通訳向けの別チャンネルは不要。
- Firebase の利用者は当分オーナー1人（Firestore ルールの反映は急がない）。
- LINE の担当者は10月分で十分。社内マニュアル（Moldel hang xom・フェンスとブロック塀の作成・manual）は案件ではない。
- 帳票はスプレッドシートの雛形で書いて PDF で出す。売上総合報告書は毎月、案件の無い状態から作る。

## 5. 決まっていないこと・確認したいこと（オーナーに聞く）

- 発注書のお客様名の位置：今は右側の K17 に入れている。違えば `BL_LAYOUTS.order.customer` を直す。
- 請求書の軽減税率（8%）は扱っていない（10% のみ）。
- 売上総合報告書で「入れる区分が無い」と出た会社（ラボの新しい会社など）の扱い：雛形に区分を足すか、どの区分に入れるか。
- 『案件入力』で外した視点は消さない（作業時間を守るため）。消す運用が要るか。
