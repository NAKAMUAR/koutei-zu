## 4. 手順

### 4-1. スクリプトを入れる（どちらか）

**A. clasp（コマンド）で送る**（docs/08 の 2-9）

1. オーナーに https://script.google.com/home/usersettings を kei.n412 で開き、「Google Apps Script API」をオンにしてもらう。
2. 管理者用シートの「拡張機能 → Apps Script」→ 歯車（プロジェクトの設定）→ スクリプト ID をコピーしてもらう。
   まだ Apps Script を一度も開いていない場合は、開いた時点でシートに紐づいたプロジェクトができる。
3. `.clasp.json.example` を `.clasp.json` にコピーし、`scriptId` に貼る（`.clasp.json`・`~/.clasprc.json` はリポジトリに入れない。`.gitignore` 済み）。
4. `npm run gas:login` → ブラウザで kei.n412 を選んで許可（オーナーの操作）。
5. `npm run gas:push`（`Code.gs` と `appsscript.json` だけを送る。Apps Script 側の他のファイルは消える）。

**B. 貼り付け**

1. 管理者用シート →「拡張機能 → Apps Script」→「コード.gs」の中身を全部消し、`sync/Code.gs` の全文を貼って保存。
2. （任意）歯車 →「"appsscript.json" マニフェスト ファイルをエディタで表示する」をオン → `sync/appsscript.json` の中身を貼って保存。日付・時刻はコード側でベトナム時間に固定してあるので、省いても動く。

### 4-2. 初期設定と承認（オーナーの操作）

1. 管理者用シートを再読み込み → メニュー「工程図連携」→「**0. かんたん初期設定（最初に1回だけ）**」。
2. 承認画面：「続行」→ kei.n412 を選ぶ →「このアプリは Google で確認されていません」なら「詳細」→「（安全ではないページ）に移動」→「許可」。
3. 許可のあと、もう一度「0. かんたん初期設定」を押し、結果がすべて ✓ になることを確認する。
   - これで設定されるもの：30分ごとの自動実行（`autoRun`）、入力シートの編集トリガー（`onStaffEdit`）、管理者シートの編集トリガー（`onAdminEdit`）、両シートのタイムゾーン。

### 4-3. Discord

1. Discord のチャンネル →「チャンネルの編集 → 連携サービス → ウェブフック → 新しいウェブフック → ウェブフックURLをコピー」。
2. メニュー「工程図連携 → Discord 通知の設定（Webhook URL）」に貼る（スクリプトプロパティ `DISCORD_WEBHOOK_URL` にだけ保存される。リポジトリ・シートに書かない）。
3. メニュー「Discord 通知のテスト送信」で届くことを確認。

### 4-4. 既定の担当者

『設定』の「既定の担当者（ホワイト／カラー／pts／写真合成・モデル・VR・動画）」にオーナーから名前を聞いて入れる（空でも動く。空なら「既定の担当者」＝未割当）。

## 6. うまくいかないとき

- メニュー「工程図連携」が出ない：シートを再読み込み。Apps Script の保存を確かめる。
- 「0. かんたん初期設定」で ✗：結果の文に理由と対処が出る（エンジニア入力シートの編集権限・工程図との接続など）。docs/08 の 6「困ったとき」。
- 書いてもすぐ写らない：『案件登録』以外のタブでは動かない。会社コード・案件番号・視点・新規or修正がそろっているか。トリガーは Apps Script の「トリガー」（時計のマーク）に `autoRun`・`onStaffEdit`・`onAdminEdit` の3つがあるか。
- 実行ログ：Apps Script の「実行数」に、エラーの内容が出る。
- メニューを押すと「エラーが発生しました（まず、再読み込みしてください）」が出て、「実行数」に記録も残らない：承認のときに**一部の権限のチェックが外れたまま**許可している。Apps Script のエディタで関数 `quickSetup` を選んで「実行」→「承認が必要です」→「権限を確認」→ 権限の一覧で「すべて選択」にチェックして許可する（2026-11-03 の設置で発生）。`quickSetup` はエディタから実行しても動き、結果は「実行ログ」に出る。
- 「The database (default) does not exist」：工程図の Firestore のデータベース名は `default`（カッコなし）。`sync/Code.gs` の `FIRESTORE_DATABASE_ID` で指定している（2026-11-03 に修正済み。古い Code.gs を貼ると再発する）。
